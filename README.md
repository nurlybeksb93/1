# BHS Fight Night

Мобильный лендинг встречи Beta High School 21 ноября 2026 года, на русском и казахском языках. Сбор предварительно в 20:00, бой ориентировочно в 23:00. Адрес: Тажибаевой, 155, здание «31 канала». В программе просмотр и турнир по UFC на PS5.

## Запуск

Нужен Node.js 24 или новее. Сторонних зависимостей нет.

```sh
cd /workspace/1
npm start
```

Порт по умолчанию 3000, можно задать `PORT`. Для публичной ссылки нужен хостинг с Node.js, HTTPS и постоянным диском для `data/`. Процесс запускается заново после перезапуска среды.

## Регистрации

Форма отправляет заявки в Google Apps Script и показывает успех только после ответа `ok: true`. Адрес обработчика указан в `public/app.js`. Старый локальный маршрут `POST /api/register` также доступен при запуске Node.js и сохраняет данные в SQLite, но форма его больше не использует. Имя и телефон принадлежат взрослому; для детей собирается только количество. Доступа к списку заявок через публичный API нет. Базу не добавлять в Git, хранить резервные копии и удалять данные после окончания организационной необходимости. До рассылки нужно согласовать с организаторами контакт, условия участия детей, правила обработки данных и проверить опубликованный сайт. Автоматической рассылки WhatsApp нет.

Тексты и программа: `public/app.js` (оба языка), исходная разметка: `public/index.html`, оформление: `public/style.css`. Год 2026 принят по дате создания проекта; заявленное расписание боя независимо не проверялось.

## Проверки

```sh
npm test
```

HTTP-проверка запуска: GET `/` возвращает страницу, корректный POST `/api/register` — 201, некорректный — 400. Для тестовых запросов используйте вымышленные данные и отдельную копию приложения, чтобы не загрязнять базу участников.

## Бесплатная публикация

GitHub → Settings → Pages → Deploy from a branch → main → / (root) → Save. Корневой index.html использует ресурсы из public/. При изменении разметки public/index.html обновляйте также корневой index.html с путями ./public/. Google Таблица должна оставаться закрытой; веб-приложение Apps Script должно быть доступно всем и выполняться от имени владельца. Реальный приём заявки необходимо проверить после публикации: запись в таблице и подтверждение в форме.
